# Astroart

> One named Astroart session. Finish the plate solve. Leave a note the next person can read.

## Session Card

| Slice | What you do in Astroart | What remains |
|-------|------------------------|--------------|
| Arrival | Open Astroart and name tonight's observatory desk | A titled night session |
| Focus | Keep only the live frame set on the Astroart board | A short process list |
| Check | Read Astroart plate solve before you trust the field | A confirmed image set |
| Handoff | Mark finished stacks inside Astroart | A note for the next visit |

## How Astroart Sits

Astroart does not replace the camera, the mount, or the planetarium you already use. It sits beside them as a named observatory desk for one job: which camera session is live, which frames still need a plate solve, and what the next person should read until morning.

## Traffic Light

| Signal | On the Astroart board | What you do |
|--------|----------------------|-------------|
| Green | Named session, short live frame list | Continue the same night desk |
| Amber | Calibration mixed with an unsolved stack | Split the set before a plate solve |
| Red | No title, no note, frames unlabeled | Stop and name the session first |
| Clear | Handoff written, live frames few | Close Astroart and leave the desk |

![Astroart](https://www.msb-astroart.com/images/icodesk2.jpg)

## Open Order

1. Open the last Astroart session, not a new empty observatory desk.
2. Read the process list and the last handoff.
3. Finish one visible stack inside Astroart.
4. Write what changed, then close with fewer unlabeled frames than you found.
5. If the set feels crowded, drop anything that belongs to a different Astroart night.

## Desk Fit

| Who | What Astroart holds |
|-----|--------------------|
| Observatory | Camera session, stack, and plate solve on one desk |
| Backyard | Named night set on the PC beside the mount |
| Shared desk | One Astroart profile per person |
| Archive | Finished nights off the live observatory desk |

## After a Week

A week in Astroart is not a longer unsolved pile. It is the same title, a shorter live session, and a note that still makes sense at dawn. Take finished stacks off the live set so the next visit starts on frames that still need a plate solve.

## Sign-off

- [ ] The Astroart workspace name is short enough to scan
- [ ] Only the live night set is on the board
- [ ] A second person can read the handoff
- [ ] The last Astroart session still opens after a restart

## Field Note

Astroart is easier to trust when the observatory desk stays smaller than the frame folder it came from. Name the session, keep the live camera set, finish one visible plate solve, and write what changed.
